# Roadmap 与验收标准

> 本文列出计划，不代表已实现。严格约束：独立 MyGo Native 应用；不修改 Magpie、不代理流量、不写 Magpie 数据。

## M0 — 接入契约与证据

- 明确 Gateway 实际地址、运行版本及权限规则。
- 获取经过脱敏的 `/v1/magpie/concurrency`、单 Session `/v1/magpie/route`、`/v1/magpie/usage/requests` 响应样本。
- 验证普通配置和 portable 配置目录；完整读取真实 JSONL 和 gzip 历史。
- 对比原版 GUI 的 Request ID、Session、模型、候选顺序、错误和完成状态。

**验收**：API 数据模型单元测试和历史解析金样例测试均通过；报告不可用字段，而不是猜测。

## M1 — 可独立运行的 Native 客户端

- MyGo Native 模板，跨平台构建脚本与基础窗口。
- 连接配置、Gateway 存活状态、诊断页与错误提示。
- HTTP 客户端、断线重试、并发采样和后台状态处理。
- Go Route Store：活动请求与完成历史以 `Route.ID` 合并，未匹配不假设同一条请求。

**验收**：断开/恢复 Magpie 时客户端不崩溃；Magpie 不受客户端退出影响；运行时网络监控无任何模型请求被 MyGo 中转。

## M2 — 路由主界面（Native）

- 按原版布局实现 Agent → Gateway → Provider/Account/Model 节点。
- 原生曲线路径、节点选中、连线高亮及动画；支持多请求并发。
- 请求列表、过滤、选中详情，来源标签 Live/Completed/Replay。
- 未收到对应数据时明确标注“未观测到”，不做假实时路由动画。

**验收**：多请求时无错误串线；所有展示的模型、账号、状态可追溯到实际 API 或历史字段；不使用 WebView。

## M3 — 历史与回放

- 按日期读取 JSONL / GZIP；文件尾随和定时扫描兜底。
- 同一请求的候选路径和 Try 逐步播放，带暂停、倍速、定位。
- 保证历史日期与本地时区展示一致；按天数据过大时保持 UI 流畅。

**验收**：跨日、异步晚写、部分 JSONL 行、gzip、多条同 ID 去重和故障重启测试均通过；动画标记为历史回放。

## M4 — 路由组展示与稳定性

- 只读路由组列表、静态成员、顺序、权重、策略及可观察字段。
- 来源分别标注为静态配置、模型目录与实时配额，不等同于动态完整求值。
- 文件数据变化刷新，配置不可读/升级结构不兼容时保留最后成功视图。
- 性能回归、匿名诊断包、截图脱敏、操作文档与发布包。

**验收**：绝不修改 `providers.json`；对缺失的自动组和运行时状态有清晰说明。

## 候选 M5 — 上游可观测性增强（不纳入硬性承诺）

只有当 Magpie 官方 Gateway 提供经授权的全局只读 Trace API 和路由组管理 API，或项目约束明确改变，才考虑：

- 运行中全部请求的逐步实时尝试和候选账号更新。
- 完整的路由组编辑、创建、删除、排序和并发冲突保护。

不能通过静态文件猜测实时事件，不能以直接改 `providers.json` 冒充正规管理 API。

## 质量测试清单

| 范围 | 核心场景 |
| --- | --- |
| 协议 | 成功、401/403、404、5xx、超时、未知字段 |
| 路由关联 | 活动 ID 与 Route ID 区分、重启后 ID 分配、无 Session、重复 Session |
| 历史 | 增量写入半行、跨日、gzip、截断/文件轮转、权限不足 |
| Native 绘制 | 高 DPI、不同窗口大小、系统缩放、动画中多 Route 更新 |
| 动画回归 | Canvas 尺寸/DPI 失效、暂停回放停止帧请求、直接 Seek 返回段、超过 4 Agent / 5 Provider 的并发端点 |
| 性能 | 多请求并发、密集 Trace 更新、长历史、不在 UI 主线程解压 |
| 安全 | Key 不落日志、请求文本脱敏、数据目录只读、只连接配置过的目标 |
| 可用性 | Magpie 未运行、重启、不同版本、portable 模式 |

## 风险登记

- **最高风险**：上游无全局公开 Trace，运行中多路由细节无法对等展示。
- **较高风险**：版本变化引发文件/字段兼容；严格按版本契约测试。
- **较高风险**：路由组运行时自动求值与 `providers.json` 静态不等价。
- **中等风险**：磁盘异步写入和轮转导致 UI 感知延迟。
- **中等风险**：原版 SVG/DOM 的动画机制需重新设计为 MyGo 原生绘制，不能简单复用 JS。
